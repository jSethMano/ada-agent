## Summary

Use this guide when an approved work application fails to launch, closes unexpectedly, or becomes unresponsive during normal use. The application may display an error, close immediately after opening, or freeze before you can use it.

## Steps

1. If an error message appears, note its exact wording and take a screenshot if permitted by company policy. Avoid capturing confidential information unnecessarily.
2. Make sure you are opening the correct application through its usual approved shortcut or company-provided launcher.
3. If the application requires a network connection, verify that your internet or company network connection is working.
4. Close the application normally. If it is unresponsive, use the standard application-closing controls available on your device.
5. Check whether the problem occurs only with one application, one document, or multiple applications.

## If that didn't work

- Save your work in other applications, restart the computer, and try opening the affected application again.
- Ask the IT helpdesk whether there is a known application or related service outage.
- Follow approved update notifications available to your account. Do not download replacement installers from unfamiliar websites.

Do not uninstall company software or change restricted system settings without IT approval.

## When to file a ticket

File a ticket if the application still fails after restarting, displays a recurring error, or prevents you from completing essential work. Include the application name, device details, error text, when the issue began, and the steps that reproduce the failure.
