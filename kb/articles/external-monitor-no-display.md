## Summary

Use this guide when an external monitor connected to your work laptop displays a blank screen, reports no signal, or is not detected by the computer. The problem may involve monitor power, the selected input source, a loose cable, or display settings.

## Steps

1. Confirm that the monitor is switched on and its power cable is securely connected.
2. Use the monitor's normal controls to select the input corresponding to its connected cable.
3. Check that the video cable is securely attached at both ends and look for visible damage.
4. If using an approved docking station or adapter, ensure it is firmly connected to both the laptop and monitor.
5. Open the standard display settings available to your account and check whether the operating system recognizes the second monitor.
6. If the monitor is detected, select the normal extended or duplicated display mode appropriate for your work.

## If that didn't work

- Disconnect and reconnect the display cable, then restart the laptop if necessary.
- If an approved spare cable or monitor is available, test it to help determine whether the issue involves the cable, monitor, or laptop.
- Record any displayed error, such as a no-signal message, and whether the screen works intermittently.

Do not open the monitor casing or install unapproved display drivers.

## When to file a ticket

File a ticket if the monitor remains blank, is not detected, or repeatedly loses its signal after these checks. Include the laptop model, monitor location or asset number, connection type, displayed error, and whether another approved cable or monitor works.
