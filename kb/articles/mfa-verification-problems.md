## Summary

Use this guide when you cannot complete multi-factor authentication (MFA) while signing in to a company account. Common symptoms include missing verification codes, authentication prompts that do not appear, rejected one-time codes, or an unavailable registered device.

## Steps

1. Confirm that you are signing in to the correct work account and that the requested verification method matches one you registered.
2. Check your phone's power and, where necessary, its internet or mobile signal so it can receive the authentication request.
3. Open your approved authentication application or check your registered message inbox for the expected prompt or code.
4. If your authentication application generates time-based codes, check that your device's date and time are set automatically.
5. If the first code expires, request another through the official sign-in page and use the most recent code promptly.
6. If offered, select another verification method that you have already registered.

## If that didn't work

- Check the official sign-in instructions for the company's MFA recovery process.
- Ask the IT helpdesk for assistance if your registered authentication device is unavailable.
- Note whether the problem affects code delivery, code validation, or approval prompts.

Never approve an authentication request that you did not initiate. Do not disclose verification codes to anyone, including someone claiming to be from IT.

## When to file a ticket

File a ticket if valid verification codes cannot be received, you have lost access to your registered device, or you suspect unauthorized authentication requests. Include the affected service, verification method, error message, and approximate time of the problem. Do not include actual authentication codes.
