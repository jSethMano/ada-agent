## Summary

Use this guide when you have forgotten your work account password or cannot sign in because your password has expired. Common symptoms include rejected credentials, unsuccessful sign-in attempts, or a prompt to reset your password.

## Steps

1. Confirm that you are entering your assigned work username or email address without accidental spaces or spelling errors.
2. Check that Caps Lock is not enabled and that your keyboard language or layout is correct.
3. Open your company's official sign-in page and select the available password recovery or reset option.
4. Follow the identity verification instructions using only recovery methods you previously registered.
5. Create a new password that meets company requirements. Avoid reusing an old password or a password used for personal accounts.
6. Return to the original sign-in page and sign in with the new password. If prompted, update the password in approved applications that require it.

## If that didn't work

- Recheck the username, keyboard settings, and any error message displayed during sign-in.
- Use only the official recovery process if another password reset attempt is necessary.
- Ask the IT helpdesk for assistance if recovery is unavailable or identity verification cannot be completed.

Never share your password or verification codes with another person.

## When to file a ticket

File a ticket if you cannot complete identity verification, the recovery option is unavailable, or your new password is repeatedly rejected. Include the affected service, the time of the failed attempt, and the exact error message. Never include your password or verification code.
