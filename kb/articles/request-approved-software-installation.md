## Summary

Use this guide when you need a company-approved application for your job but cannot find it on your device or do not have permission to install it. The operating system may request administrator approval, or the application may require a company license or account assignment.

## Steps

1. Identify the task you need to perform and the application that supports it. Check whether an existing company-approved application already meets the requirement.
2. Review your company's software catalog, standard application launcher, or onboarding instructions to see whether the application is already available.
3. Check any available information about whether the application requires a company license, account assignment, or manager approval.
4. Record the application's name, its intended business purpose, your device type, and any required integration or compatibility details.
5. Submit a software request through the company's approved IT support process. Provide a business justification and any required approval.
6. Follow the support team's instructions regarding installation, licensing, and access.

## If that didn't work

- Continue using approved tools while the request is being reviewed.
- If the application becomes available, open it and follow the approved sign-in or setup instructions.
- Ask the IT helpdesk whether additional business justification, licensing information, or approval is required.

Do not bypass administrator restrictions, use personal administrator credentials, or download unverified installers from third-party websites.

## When to file a ticket

File a software request if the required application is unavailable through approved channels, requires elevated privileges, or needs a new license. Include the business purpose, application name, device details, and any relevant compatibility requirements. Submit a separate incident ticket if an already-installed application has unexpectedly stopped working.
