## Summary

Use this guide when you cannot open a shared company folder or document that you normally use for work. You may see an access-denied message, find that a shared location is missing, or discover that a previously available file is no longer accessible.

## Steps

1. Verify that you are signed in with your assigned work account rather than a personal or secondary account.
2. Confirm that you are using the correct shared location or approved shortcut. Check the original link or instructions supplied by your team.
3. If the shared folder requires the office network or VPN, verify that you are connected through the approved method.
4. Navigate to the shared folder through the company's standard file system or approved document portal instead of an old bookmark.
5. Determine whether the problem affects one file, one folder, or several shared locations.
6. If appropriate, ask a teammate who is authorized to use the same folder whether they can access it.

## If that didn't work

- Ask the IT helpdesk whether there is a known shared-storage outage.
- Record the folder location and exact error message without copying sensitive document contents into an unrelated request.
- Check the company's approved access instructions for the affected shared location.

Do not attempt to change folder permissions, use another employee's account, or move restricted files to a personal storage service.

## When to file a ticket

File a ticket if access remains denied, a previously available folder disappears, or you need authorization for a new folder. Include the folder path or approved link, the business reason for access, the error message, and whether teammates are affected.
